# حسابداری فیکس کوییک (نسخه ۱.۰)

برنامه حسابداری آفلاین و تک‌کاربره برای اندروید. همه اطلاعات روی خود گوشی ذخیره می‌شود و به اینترنت نیازی ندارد.

## امکانات
- **اشخاص:** حساب مشتری و تأمین‌کننده، مانده اول دوره، صورت‌حساب با مانده لحظه‌ای، فیلتر بازه زمانی، ارسال متن صورت‌حساب و خروجی CSV
- **فاکتور:** چهار نوع فاکتور (فروش، خرید، برگشت از فروش، برگشت از خرید)، تخفیف، تسویه همزمان (نقد/کارت/چک) و ثبت پرداخت‌های بعدی
- **انبار:** موجودی لحظه‌ای با **میانگین موزون**، جلوگیری از فروش بیش از موجودی (حتی با فاکتور تاریخ‌گذشته)، تعدیل موجودی و کاردکس کالا
- **دریافت و پرداخت:** حواله بین اشخاص، هزینه‌ها، چک و اقساط با هشدار سررسید
- **گزارش:** سود و زیان (فروش خالص، بهای تمام‌شده، سود ناخالص، هزینه‌ها، سود خالص)، گردش نقد و بانک، مطالبات و بدهی‌ها، پرفروش‌ها
- **عمومی:** تقویم شمسی دقیق، قفل رمز ۴ رقمی، پشتیبان‌گیری و بازیابی، بررسی سلامت اطلاعات، حالت تاریک

## ساخت APK (فقط با گوشی و Termux)
این پروژه کد برنامه است. فایل APK روی سرورهای GitHub (رایگان) ساخته می‌شود.

**۱.** فایل `fixquick-app.zip` را در پوشه Download گوشی ذخیره کنید.

**۲.** در Termux بزنید:
```bash
pkg install git gh unzip -y
cd ~ && unzip -o ~/storage/downloads/fixquick-app.zip && cd fixquick-app
git config --global user.name "Mohammad"
git config --global user.email "you@example.com"
gh auth login
```
در `gh auth login` این گزینه‌ها را انتخاب کنید: `GitHub.com` ← `HTTPS` ← `Y` ← `Login with a web browser`. کد ۸ رقمی را در مرورگر وارد کنید.

**۳.** آپلود و شروع ساخت:
```bash
git init && git branch -M main && git add . && git commit -m "Fix Quick Accounting 1.0"
gh repo create fixquick-app --private --source=. --remote=origin --push
```

**۴.** پیشرفت ساخت را دنبال کنید (حدود ۵ تا ۱۰ دقیقه):
```bash
gh run watch
```

**۵.** APK را مستقیم در پوشه Download دریافت کنید:
```bash
gh release download latest -p "*.apk" -D ~/storage/downloads --clobber
```
بعد فایل `FixQuick-Accounting.apk` را از Download باز و نصب کنید. باید اجازه «نصب از منابع ناشناس» را برای فایل‌منیجر بدهید.

**به‌روزرسانی‌های بعدی:** فایل‌های جدید را جایگزین کنید، بعد `git add . && git commit -m update && git push` بزنید و مرحله ۴ و ۵ را تکرار کنید. نسخه جدید روی نسخه قبلی نصب می‌شود و اطلاعات می‌ماند.

## نکته‌های مهم
- **پشتیبان:** با حذف برنامه، اطلاعات پاک می‌شود. مرتب از «بیشتر ← تنظیمات ← دریافت پشتیبان» نسخه بگیرید و فایل را برای خودتان بفرستید (تلگرام، Drive و…).
- **کلید امضا:** پوشه `android-signing` کلید امضای برنامه است. با آن، نسخه‌های بعدی روی نسخه قبلی نصب می‌شوند. **repository را Private نگه دارید.**
- **رمز برنامه:** اگر رمز را فراموش کنید قابل بازیابی نیست. فقط با پاک‌کردن اطلاعات برنامه و بازیابی پشتیبان می‌شود دوباره وارد شد.

## ساختار
- `www/` — خود برنامه (HTML/CSS/JS، بدون وابستگی خارجی)
  - `core.js` — موتور حسابداری
  - `base.js` و `pages.js` — رابط کاربری
- `tests/` — تست‌ها
  - `core.test.js` — ۲۳ تست موتور، شامل تطبیق تقویم شمسی روز به روز در ۷۰ سال
  - `e2e.py` و `back.py` — تست مرورگر
- `tools/android_assets.py` — آیکون و صفحه شروع اندروید
- `.github/workflows/build-apk.yml` — ساخت خودکار APK
